# ATOMON HELPER

ATOMMONSTERS カードゲーム用の化合物検索・合成サポートWebアプリです。

## 機能

- **化合物検索** — 所持している原子（アトモン）から作れる化合物を一覧表示
- **原子インベントリ管理** — 各元素の所持数をタップ/クリックで増減
- **長押し入力** — 数値を素早く増やせる長押し操作に対応
- **召喚済みリスト** — 入手済みの化合物をチェック管理
- **パック選択** — Basic / Green など収録パックに対応した初期配布アトモンセット
- **バージョン選択** — ゲームのバージョンに合わせて化合物データを切り替え
- **テーマ切替** — space / candy / aqua / sunshine / berry の5テーマ
- **PWA対応** — ホーム画面に追加してオフラインでも使用可能

## ファイル構成

```
atommonsters-helper/
├── index.html          # メインHTML
├── manifest.json       # PWAマニフェスト
├── css/
│   └── style.css       # スタイルシート
├── js/
│   ├── app.js          # UIコントローラー
│   └── logic.js        # 化合物検索・合成判定ロジック
├── data/
│   ├── atoms.json      # 原子データ
│   └── compounds.json  # 化合物データ

    ├── Atomon_basic/   # Basic版アトモン画像
    ├── Atomon_green/   # Green版アトモン画像
    ├── Atomon_image/   # アイコン・共通画像
    └── Atomon_purple/  # Purple版アトモン画像
```

## 使い方

1. **パック選択** — 持っているパックを選択すると初期アトモンが自動セット
2. **原子数調整** — 各元素のカードをタップして所持数を増減
3. **化合物リスト確認** — 作れる化合物が上位に表示される
4. **召喚済みチェック** — 入手した化合物にチェックを入れて管理

## 動作環境

モダンブラウザ（Chrome / Safari / Firefox）でそのまま動作します。サーバー不要、ローカルファイルとして開いても動きます。

## データ

- `data/atoms.json` — 原子の元素記号・名前・画像パスなど
- `data/compounds.json` — 化合物名・必要元素・画像パスなど

データを更新することでゲームの新バージョンに対応できます。
